# 国产模型使用说明（豆包 / 千问 / Kimi / DeepSeek）

不用装任何软件，复制粘贴就能用。

## 方法一：直接在对话里用（所有平台都可以，最简单）

1. 打开任意一个提示词文件，比如「01-孙子兵法·竞争决策-提示词.md」。
2. 复制「===== 复制开始 =====」到「===== 复制结束 =====」之间的**全部内容**。
3. 在豆包、千问、Kimi 或 DeepSeek 里**新建一个对话**，把内容粘贴进去发送。
4. 它会先跟你打招呼，然后你直接说你的问题。

注意：同一个对话里一直用就行。开了新对话需要重新粘贴。

## 方法二：做成自己的专属智能体（可以反复用，推荐）

豆包、通义千问、Kimi 等平台一般都有"创建智能体 / 创建 AI 助手"一类的功能（各平台的名称和位置可能不同，也会随版本变化）。

1. 找到平台的"创建智能体"入口。
2. 名称填：孙子兵法竞争顾问（或老子知止顾问、王阳明行动教练）。
3. 把复制的内容粘贴到"设定 / 人设 / 系统提示词 / 回复逻辑"这一栏。
4. 保存。以后直接打开这个智能体提问就行。

如果平台对设定的字数有限制、粘贴不进去：
- 优先保留「你的身份」「工作流程」「经典依据库」「回答格式」这几段；
- 「输出前自检」和「边界」可以改成更简短的几句话，但不建议全删。

## 怎么问效果最好

尽量说清楚这四件事：

1. **你的目标**：你想达到什么结果？
2. **现在的情况**：已经确认的事实和数据，比如营业额、粉丝数、投入了多少钱和时间。
3. **你的资源**：钱、时间、人手各有多少？
4. **你最担心什么**：最坏能接受什么样的结果？

例子：
> 我在小区开了一家奶茶店，开业 8 个月，每月勉强持平。对面新开了一家连锁品牌，第二杯半价。我手上还有 3 万元周转资金，最多能亏 1 万。要不要跟着降价？

## 几个小技巧

- 说"**行动模式**"：只给推荐和第一步，不讲道理。
- 说"**别直接给答案**"：它会一步步提问，引导你自己想清楚。
- 做完第一步后**回来汇报结果**：它会根据新情况调整判断，越用越准。

## 模型选择建议

- 推荐用各平台的"深度思考 / 推理"模式，分析会更完整。
- 不同模型的回答风格会有差别，可以多试几个，选你觉得最好用的。
