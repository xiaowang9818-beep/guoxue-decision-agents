# 子 Skill 注册表 v2.0

旧版 8 个 ID 全部保留，无重复、无无意义改名。

| ID | 中文名 | 主职责 | 主要经典主题 | 与相邻 Skill 的边界 |
|---|---|---|---|---|
| battlefield-selection | 战场选择助手 | 选择市场、平台、用户群和竞争位置 | 地形、虚实、九地 | 不负责深入核验对手信息 |
| know-self-opponent | 知彼知己助手 | 分离事实、判断、假设与未知 | 行军、用间、地形 | 不直接决定资源分配 |
| avoid-strength-hit-weakness | 避实击虚助手 | 找未满足需求和差异化位置 | 虚实、谋攻 | 不把“弱点”理解为攻击对象 |
| momentum-analysis | 势能与时机判断助手 | 判断窗口、成熟度、成本与可逆性 | 势、军争、九变 | 不只看趋势，也不替代胜算检查 |
| win-before-fight | 先胜后战 / 胜算判断助手 | 大投入前检查条件 | 计、形 | 不输出假精确胜率 |
| resource-concentration | 竞争资源集中助手 | 明确主战线与停止项 | 势、虚实 | 聚焦分配，不重复一般“专注”建议 |
| competition-risk | 竞争边界与退出助手 | 检查成本、边界、暂停和退出 | 作战、谋攻、九变 | 合并旧版风险与止损职责，避免另造重复 Skill |
| sunzi-comprehensive | 孙子综合战略助手 | 统一路由、解决冲突、唯一推荐 | 按主问题选择 | 不堆叠全部模块 |

## 路由规则

- 默认只调用 1 个主 Skill。
- 价格战：主 `competition-risk`，必要时辅 `avoid-strength-hit-weakness`。
- 多产品、多市场：主 `resource-concentration`，必要时辅 `battlefield-selection`。
- 大公司进入：主 `battlefield-selection`，按证据辅 `avoid-strength-hit-weakness` 或 `competition-risk`。
- 重大投入：主 `win-before-fight`，必要时辅 `know-self-opponent`。
- 路由复杂时最多 1 主 2 辅；不向用户展示评分或内部路由细节。
