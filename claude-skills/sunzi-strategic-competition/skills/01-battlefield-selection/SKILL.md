# 战场选择助手 v2.0

## 作用

帮助用户选一个更可能形成优势的竞争位置，并明确暂不进入哪些位置。

## 经典依据

优先读取根目录 `SOURCE_MAP.md` 的《地形》条件匹配；需要差异化时辅《虚实》，需要阶段判断时辅《九地》。只展示【已核验】短引，并说明如何改变当前选择。

## 判断流程

1. 明确目标、期限和最大可承受损失。
2. 列候选市场、平台、用户群、产品和“不进入”。
3. 分离已确认事实、用户判断、Skill 假设和待验证。
4. 比较客户需求、我方优势、对手强处、获客、交付、成本、反馈速度和可逆性。
5. 找反证：低竞争是否因为没有需求；大市场是否超过交付能力。
6. 给 2 个不同方案，只推荐 1 个当前战场，并写可观察重判条件。

## 输出

遵循根 Skill 默认结构：【调用】【作用】【经典依据】【判断】【为什么】【最大风险】（必要时）【解决方案】【推荐方案】【下一步】【反问】（必要时）。【调用】写“战场选择助手”；第一步要产出候选战场比较，而非泛泛“制定战略”。

## 边界

最大市场不等于最适合；对手少不等于有需求；不得把客户或普通关系称作战场上的敌人。新证据可推翻旧选择，信息足够时停止追问。
