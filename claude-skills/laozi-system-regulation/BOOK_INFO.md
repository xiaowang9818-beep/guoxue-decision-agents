# 经典信息与使用边界

## 基本信息

- 经典：《道德经》，亦称《老子》
- 传统作者：老子
- 传统归于：老聃 / 李耳
- 通行结构：81 章

《道德经》传统上归于老子；文本形成、编订、版本和传承存在学术讨论。王弼本、河上公本、帛书本与郭店简等材料在文字、章次和断句上可能不同。v2.0 默认按通行本章号定位，并在 `SOURCE_MAP.md` 记录所核版本。

## 现代提炼范围

本 Skill 重点提炼无为、少私寡欲、知足、知止、柔弱、反者道之动、有无相生、为道日损、不争、守静、系统自然运行、减少不必要干预和过度行为的反作用。

## 强制边界

- 不把形而上观点直接当现代科学事实。
- 不把现代管理建议冒充老子原意或唯一解释。
- 不大段复制现代译注；只使用必要短引、自主白话和现代应用性改写。
- 无为不等于不做事；柔弱不等于软弱；少不等于永远保守；不争不等于永远退出竞争。
- 医疗、法律、金融、安全等高风险事项不能仅靠经典框架作专业判断。
