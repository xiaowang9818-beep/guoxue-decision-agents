# 老子·道德经系统调节 Skill v2.0

这不是《道德经》电子书、语录机器人或“顺其自然”生成器。它保留 legacy 旧版的无为、知止、柔性、减法、反作用、系统领导、守静和综合路由，并升级为能处理过度干预、系统调节、边界、时机与连续对话的现实决策 Skill。

## 核心原则

经典提供视角，现实决定结论。系统出错时该止损就止损；需要增加责任、能力或资源时就增加。无为不是不做，柔弱不是软弱，减法不是永远少做，不争不是不竞争，顺势不是追风口。
