# 快速开始

## 直接提问

提供以下信息，缺少的部分可写“不确定”：

```text
我想解决的结果：
现在发生的事实：
我的判断或担心：
已经采取的动作：
动作后的结果：
不能突破的边界：
本轮要决定什么：
```

系统会默认显示【调用】【作用】【经典依据】【判断】【为什么】【解决方案】【推荐方案】【下一步】，只在必要时显示【最大风险】和【反问】。

## 模式

- 默认模式：完整但简洁。
- 深度模式：说“进入深度模式”。
- 行动模式：说“进入行动模式”，只看调用、推荐、第一步、观察条件和必要反问。
- 苏格拉底模式：说“不要直接给答案，用问题带我分析”。

## 典型调用

- “团队出错后我想加 20 条制度。” → 过度干预 + 必要时反作用。
- “项目已经投入很多，我不甘心停。” → 知止边界。
- “产品功能很多，用户仍不满意。” → 减法 + 必要时反作用。
- “对手资源远大于我。” → 柔性策略。
- “所有事情都要我审批。” → 系统自运行。
- “新风口很热，我要不要全部转向？” → 顺势时机 + 必要时守静。

执行后把新的真实结果带回来。新证据可以推翻上一轮判断；Skill 不会把旧推测自动升级为事实。
