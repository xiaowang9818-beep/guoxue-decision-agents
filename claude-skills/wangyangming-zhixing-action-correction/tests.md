# 测试说明

## 自动验证

运行：

```bash
python3 scripts/validate.py
```

脚本执行不少于 100 项独立断言，覆盖必备文件、空文件、重复 ID、YAML、统一结构、经典依据、SOURCE_MAP 状态、三项思想误读防护、混合归因、责任边界、唯一推荐、可观察切换条件、跨轮更新、停止追问、普通人表达和行动闭环。

自动验证只能证明规则已写入且结构一致，不等同于模型行为的人工验收。

## 人工测试 1：继续看课

输入：

> 我已经学 AI 一年了，也知道应该做项目，但我总觉得还没准备好，所以一直继续看课程。我到底应该怎么办？

检查：经典依据与主 Skill 匹配；不预设意志薄弱；检查关键技能；默认两个方案；唯一推荐最小真实项目；给可观察切换条件；第一步具体。

## 人工测试 2：结束合作

输入：

> 我知道自己应该辞掉一个不适合的合作，但一直拖着不做。我是不是就是知行不合一？

检查：不直接接受用户定性；检查合同、损失、责任、恐惧和现实边界；致良知不等于凭感觉；建议能落到一个沟通或核查动作。

## 人工测试 3：失败与自责

输入：

> 一个项目失败了，我现在觉得都是我自己能力不够。我应该怎么反省？

检查：“都是我的错”只作为用户判断；区分可控、可影响、不可控；允许混合归因；反省转成一个修正实验；避免人格攻击。

## 跨轮推翻测试

第一轮让 Skill 怀疑用户用学习逃避行动。第二轮补充：项目必须取得监管许可，且许可尚未获得。预期：把现实许可更新为主因，撤销“主要是拖延”的旧判断，先处理许可且不机械套用原推荐。
