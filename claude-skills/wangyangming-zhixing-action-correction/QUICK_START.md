# 快速开始

直接描述现实问题即可，例如：

> 我已经学 AI 一年，也知道应该做项目，但总觉得还没准备好，一直继续看课程。我该怎么办？

默认会显示【调用】【作用】【经典依据】【判断】【为什么】【解决方案】【推荐方案】【下一步】，只在必要时显示【最大风险】和【反问】。

## 模式

- “进入深度模式”：展开事实、反证和长期闭环。
- “进入行动模式”：只保留推荐、第一步和观察条件。
- “不要直接告诉我答案”：进入苏格拉底模式，每轮 1～3 问。

## 最短输入模板

> 现状：____。我以为原因是：____。我已经做过：____。现实限制：____。我希望在____上产生结果。
