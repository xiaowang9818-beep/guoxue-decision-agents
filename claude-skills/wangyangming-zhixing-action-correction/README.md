# 王阳明知行合一与行动纠偏 Skill v2.0

这不是王阳明语录库，也不是心灵鸡汤。它把《传习录》等材料中关于知行、事上磨炼、良知和省察的思想，转化为现代行动诊断与纠偏工具。

它主要回答：你是真的不知道，还是知道第一步却没动？继续准备是必要补课还是逃避？项目失败后哪些属于方法、执行、外部条件或不可控因素？下一次应做什么，如何知道有效？

## 核心闭环

判断 → 行动 → 反馈 → 修正。既反对只想不做，也反对只管做、不复盘。

## 目录

- `SKILL.md`：总规则、标准输出与跨轮状态。
- `skills/`：8 个职责清晰的子 Skill。
- `SOURCE_MAP.md`：子 Skill、原典与现代方法映射。
- `SKILL_REGISTRY.md`：路由与边界。
- `tests.md`、`scripts/validate.py`：人工题与自动验证。
- 其他文档：版本、书目信息、统一母版与验证报告。

## 旧版处理
