# 王阳明经典来源映射

## 使用规则

只可短引【已核验】条目。待核验内容只能概括并明确标注，不得作为确定原文展示。使用时至少给出来源、核心思想和现代化解释；经典必须改变或支撑判断、反证、行动设计。下列“现代方法”是产品化转译，不宣称原典直接提出了现代管理或心理学模型。

## Z01 知与行不能割裂

- 经典 / 文献：《传习录》卷上
- 主题：知行合一
- 具体出处：徐爱录，第 5 条
- 可信状态：【已核验】
- 短原文：“知是行之始，行是知之成。”
- 白话解释：真正的认识会在行动中表现并被完成；口头理解不能直接等于已经掌握。
- 核心方法：检查认识是否产生行动、结果和修正。
- 对应子 Skill：01、03、07、08
- 适用问题：学很多却无产出；自称“懂了”但没有现实变化。
- 不适用问题：尚缺安全信息、许可或关键能力时，不可据此要求鲁莽行动。
- 核验来源：[维基文库《传习录/卷上》徐爱录](https://zh.wikisource.org/zh-hans/%E5%82%B3%E7%BF%92%E9%8C%84/%E5%8D%B7%E4%B8%8A)

## Z02 防止盲动与空想

- 经典 / 文献：《传习录》卷上
- 主题：知行合一的补偏救弊
- 具体出处：徐爱录，第 5 条
- 可信状态：【已核验】
- 短原文：“全不解思惟省察，也只是个冥行妄作。”
- 白话解释：只行动而不思考、检查，同样偏离知行合一。
- 核心方法：必要判断 → 小规模行动 → 反馈 → 修正。
- 对应子 Skill：01、03、04、07、08
- 适用问题：把“马上做”当万能答案；高风险盲试。
- 不适用问题：不用于为无限准备找借口。
- 核验来源：[维基文库《传习录/卷上》徐爱录](https://zh.wikisource.org/zh-hans/%E5%82%B3%E7%BF%92%E9%8C%84/%E5%8D%B7%E4%B8%8A)

## Z03 学问包含实际履行

- 经典 / 文献：《传习录》卷中
- 主题：学问思辨行
- 具体出处：《答顾东桥书》，第 136 条
- 可信状态：【已核验】
- 短原文：“尽天下之学，无有不行而可以言学者。”
- 白话解释：学习不是先囤积完知识再行动；提问、思考、辨别和履行共同构成学习。
- 核心方法：以真实任务暴露缺口，再定向补课。
- 对应子 Skill：01、03、04、07
- 适用问题：课程依赖、过度准备、实践学习。
- 不适用问题：不否定必要基础训练。
- 核验来源：[维基文库《传习录/卷中》答顾东桥书](https://zh.wikisource.org/zh-hans/%E5%82%B3%E7%BF%92%E9%8C%84/%E5%8D%B7%E4%B8%AD)

## Z04 事上磨炼

- 经典 / 文献：《传习录》卷上
- 主题：在真实事情中用功
- 具体出处：陆澄录，第 23 条
- 可信状态：【已核验】
- 短原文：“人须在事上磨，方立得住。”
- 白话解释：脱离真实场景的自我感觉，不能证明能力和判断稳定。
- 核心方法：真实任务暴露缺口 → 针对补充 → 返回任务。
- 对应子 Skill：04、05、07、08
- 适用问题：学销售、管理、AI、写作却缺少真实任务。
- 不适用问题：高危工作、专业操作或重大损失场景需先训练与保护。
- 核验来源：[维基文库《传习录/卷上》陆澄录](https://zh.wikisource.org/zh-hans/%E5%82%B3%E7%BF%92%E9%8C%84/%E5%8D%B7%E4%B8%8A)

## Z05 良知不是任性

- 经典 / 文献：《传习录》卷上
- 主题：良知与私意障碍
- 具体出处：徐爱录，第 8 条
- 可信状态：【已核验】
- 短原文：“知是心之本体，心自然会知。”
- 白话解释：原典讨论的是道德判断与私意遮蔽，不能转译成“我有感觉就一定对”。
- 核心方法：检查动机与一致性，同时接受事实、责任、法律、后果和他人权益检验。
- 对应子 Skill：02、06、08
- 适用问题：价值冲突、合理化、只想听自己愿意听的答案。
- 不适用问题：不替代专业事实判断。
- 核验来源：[维基文库《传习录/卷上》徐爱录](https://zh.wikisource.org/zh-hans/%E5%82%B3%E7%BF%92%E9%8C%84/%E5%8D%B7%E4%B8%8A)

## Z06 致良知要落实于具体事情

- 经典 / 文献：《传习录》卷中
- 主题：致知格物
- 具体出处：《答顾东桥书》，第 135 条
- 可信状态：【已核验】
- 短原文：“致吾心之良知于事事物物也。”
- 白话解释：内在原则要进入具体处事，不能停留在自我感觉。
- 核心方法：原则 + 事实 + 后果 + 现实行动。
- 对应子 Skill：02、03、06、08
- 适用问题：知道合作不合适却拖延；伦理与利益冲突。
- 不适用问题：不把个人偏好冒充普遍真理。
- 核验来源：[维基文库《传习录/卷中》答顾东桥书](https://zh.wikisource.org/zh-hans/%E5%82%B3%E7%BF%92%E9%8C%84/%E5%8D%B7%E4%B8%AD)

## Z07 心即理的边界

- 经典 / 文献：《传习录》卷上
- 主题：心即理与讲求现实条件
- 具体出处：徐爱录，第 3 条
- 可信状态：【已核验】
- 短原文：“心即理也。”
- 白话解释：这里强调道德判断不应完全外包，并不否认具体知识；紧接的问答明确承认现实“节目”仍须讲求。
- 核心方法：检查判断来源，同时核对事实、规则和具体办法。
- 对应子 Skill：02、06、08
- 适用问题：外界评价过多、动机与行动不一致。
- 不适用问题：不得解释成“只要相信就能改变客观现实”。
- 核验来源：[维基文库《传习录/卷上》徐爱录](https://zh.wikisource.org/zh-hans/%E5%82%B3%E7%BF%92%E9%8C%84/%E5%8D%B7%E4%B8%8A)

## Z08 省察必须带来修正

- 经典 / 文献：《传习录》卷上
- 主题：省察克治
- 具体出处：陆澄录，第 39 条
- 可信状态：【已核验】
- 短原文：“省察克治之功，则无时而可间。”
- 白话解释：觉察偏差之后要改具体念头和行为；现代应用不做道德羞辱。
- 核心方法：事实 → 可控偏差 → 一个修正动作 → 再验证。
- 对应子 Skill：02、05、07、08
- 适用问题：复盘、重复犯错、自责却不改变。
- 不适用问题：不把外部侵害和不可控结果归咎用户。
- 核验来源：[维基文库《传习录/卷上》陆澄录](https://zh.wikisource.org/zh-hans/%E5%82%B3%E7%BF%92%E9%8C%84/%E5%8D%B7%E4%B8%8A)

## Z09 必要知识可以询问

- 经典 / 文献：《传习录》卷下
- 主题：不知则问
- 具体出处：第 227 条
- 可信状态：【已核验】
- 短原文：“其所当知的，圣人自能问人。”
- 白话解释：行动导向不意味着假装什么都懂；真正影响安全和成败的知识应主动求证。
- 核心方法：列出最小必要信息，补齐后行动。
- 对应子 Skill：01、03、04、06
- 适用问题：合理准备与拖延的区分。
- 不适用问题：不支持无止境搜集低价值信息。
- 核验来源：[维基文库《传习录/卷下》](https://zh.wikisource.org/zh-hans/%E5%82%B3%E7%BF%92%E9%8C%84/%E5%8D%B7%E4%B8%8B)
