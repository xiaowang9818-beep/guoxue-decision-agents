# 国学决策智能体 · 开源版 v1.0

把中国经典里的决策智慧，蒸馏成能直接帮你做判断的 AI 智能体。

它不是"名言引用机"。每个智能体都有完整的诊断流程、检查清单和事实边界，最后一定会给你：**一个明确判断、一个唯一推荐、一个今天就能做的第一步**。

## 首批 3 个智能体

| 智能体 | 解决什么问题 | 典型问题 |
|---|---|---|
| **孙子兵法 · 竞争决策** | 要不要竞争、选哪里、资源押在哪、何时退出 | 隔壁降价要不要跟？大公司进场我该退出吗？ |
| **老子 · 知止决策** | 该坚持还是该放弃、做减法、止损 | 副业做了半年没起色，还要不要坚持？ |
| **王阳明 · 知行合一** | 道理都懂却做不到、拖延、过度准备 | 课买了一堆，为什么就是不开始？ |

更多经典（墨子、韩非子、资治通鉴、管子、荀子、曾国藩等）正在整理中。

## 两种用法

### 用法一：国产模型版（豆包 / 千问 / Kimi / DeepSeek），复制粘贴即用

打开 `国产模型版/` 文件夹，按 `使用说明.md` 操作。不需要安装任何东西。

### 用法二：Claude Skill 版（功能最完整）

`claude-skills/` 文件夹里是完整的 Skill。每个都包含主 Skill、8 个左右子 Skill、经典来源核验表和测试题。

- **Claude 网页版 / 桌面版**：在 Claude 设置里的技能（Skills）页面上传对应的 `.zip` 文件。
- **Claude Code**：把文件夹复制到 `~/.claude/skills/` 目录下。

## 设计原则

1. **经典只提供方法，现实证据决定结论。** 不用古文替代数据。
2. **只引用核验过的原文。** 所有短引都对照公版原典核对过，不编造原文。
3. **分清事实和猜测。** 你说"对手肯定会……"，它会标为你的判断，而不是事实。
4. **只推荐一个方案。** 不给"都可以"的模糊答案，同时写清楚出现什么信号要重新判断。
5. **安全边界。** 不支持违法、欺骗、操纵、伤害他人；涉及法律、财务、医疗时提醒咨询专业人士。
